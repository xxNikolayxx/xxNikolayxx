Тесты

В репозитории Tests_Rostelecom располагаются собственно автотесты.

>В рамках проекта мы тестируем формы авторизации, регистрации и восстановления пароля для продуктов Ростелеком. 
>Каждый файл с тестами содержит группу "нулевых" тестов, проверяющих само наличие элементов, за которыми следуют функциональные тесты для всех указанных форм конкретного продукта.
>Наиболее полный "ассортимент" тестов представлен для продукта "Старт Web"(test_start.py), т. к. именно для него доступены все функции. 
>Тесты для других продуктов сделаны на основе тестов "Старта" с учётом небольших изменений в требованиях и внешнем виде личного кабинета пользователя.


| Продукт Ростелеком  | Файл с автотестами          | Команда для запуска тестов |
| :---    |:----------------------------| :---    |
| Старт Web    | test_start(test_start.py)   | `python -m pytest -v tests/test_start.py`   |
| ЕЛК Web    | test_elk(test_elk.py)       | `python -m pytest -v tests/test_elk.py`    |
| Онлайм Web    | test_onlime(test_onlime.py) | `python -m pytest -v test_onlime.py`    |
| Ключ Web    | test_key(test_key.py)       | `python -m pytest -v tests/test_key.py`    |
| Умный дом Web    | test_shome(test_shome.py)   | `python -m pytest -v tests/test_shome.py`    |

Вспомогательные файлы

1. В репозитории Tests_Rostelecom располагаются файлы с описанием базового класса страницы, 
вспомогательных классов для определения веб-элементов, локаторов используемых 
элементов и классов целевых страниц:
Старт Web - start_pages.py,
ЕЛК Web - elk_pages.py,
Онлайм Web - onlime_pages.py,
Ключ Web - key_pages.py,
Умный дом Web - shome_pages.py.

2. Файлы функций содержит:
Файл help_functions(help_functions.py), в котором задаются несколько небольших вспомогательных функций, многократно использующихся в тестах.
Файл functions_fill_fields(functions_fill_fields.py), в который вынесены функции, заполняющие тестируемые формы данными и отправляющие их. 

3. Файлы параметров находятся тестовые данные(params_test.py) и данные для подключения к IMAP-серверу (params_imap.py).

4. Файл conftest.py содержит фикстуры.

5. Также в корневом катологе расположен драйвер для Google Chrome версии 142.0.7444.60 — chromedriver.exe
